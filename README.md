This repository contains a collection of advanced C++ algorithms and data structures that I developed to solve complex computational problems. The primary focus of this portfolio is to demonstrate a strong foundation in core computer science principles. To achieve this, all solutions were built entirely from scratch, relying on manual memory management, raw pointer manipulation, and foundational logic rather than using the C++ Standard Template Library (STL).

To showcase my ability to build and manage custom data structures, I implemented a hospital triage system using a Priority Queue. Rather than breaking data encapsulation by modifying underlying pointers directly, I maintained strict queue principles, using auxiliary structures to sort patients based on multiple priority metrics like severity, age, and arrival time. Additionally, I built a multilingual autocomplete system using a Binary Search Tree (BST). For this, I designed a recursive in-order traversal algorithm that accurately fetches and displays word suggestions in strict alphabetical order.

A significant portion of these exercises focuses on optimizing time complexity. For a patient tracking problem, I applied a Divide and Conquer strategy to identify missing records in O(log n) time using binary search mechanics. Similarly, for a security alert analysis tool, I modified a Merge Sort algorithm to count array inversions efficiently in O(n log n) time, avoiding the severe performance drops of nested iteration.

In scenarios where exhaustive search was required, such as detecting data exfiltration patterns in a server network, I implemented a structured brute-force algorithm to scan 2D traffic matrices. This required careful management of grid boundaries and coordinate tracking to identify sub-grids exceeding specific data thresholds. Furthermore, to demonstrate precise control over the execution stack, I solved a text-scanning and string-matching problem using pure recursion, completely avoiding iterative loops and standard string libraries.

Altogether, these solutions reflect my ability to write clean, optimized, and memory-safe C++ code. By building these algorithms from the ground up, I demonstrate a deep understanding of how software operates under the hood, which is a critical skill for developing efficient, scalable, and robust applications.
